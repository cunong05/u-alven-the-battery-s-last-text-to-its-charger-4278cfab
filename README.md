Entry for the [make.fun](https://make.fun/c/u-alven-the-battery-s-last-text-to-its-charger-4278cfab) bounty **"The Battery's Last Text to Its Charger"** ($2 USDC).

The task: write the phone battery's last text message to the charger it waited for all day — one line of plain text, 1–200 characters, no setup, no dialogue tag.

## The entry

> Hey, it's me — 1%. You left me on read all day, so I'm dying in a stranger's car. Tell my apps I loved them. And no, you can't charge me now. I'm ghosting you back.

164 characters, one line.

## How it works

`main.py` writes that single line to `/output/entry.txt` (literal `/output` directory, no trailing newline, UTF-8).

## Run

```sh
python3 main.py
cat /output/entry.txt
```
